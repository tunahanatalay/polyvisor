# Polyvisor

MicroVM orchestration and control plane for Firecracker, written in Rust.

**Status:** early development, not usable yet.

Planned: REST API and CLI for managing Firecracker microVMs.

## Roadmap

The architecture is intended to support other hypervisors later.
